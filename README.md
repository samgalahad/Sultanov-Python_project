# Исследование структуры и динамики налоговых поступлений в России (2006–2025)

## Автор
Студент 2 курса факультета географии и геоинформационных технологий НИУ ВШЭ группы БГЕО252 Султанов Самат

## Описание проекта
Проект посвящен анализу данных Федеральной налоговой службы (ФНС) о поступлениях в бюджетную систему РФ. 
В ходе работы были исследованы территориальные и отраслевые различия, а также проведена оценка реального роста налогов с учетом накопленной инфляции.

## Файлы
*   `sultanov.project.ipynb` - сам проект, ноутбук с кодом, графиками и текстом
*   `taxes_rus.xls` - исходный датасет от ФНС
*   `README.md` — описание

## Библиотеки
*   `pandas` - для загрузки, очистки и агрегации данных.
*   `matplotlib` - для построения визуализаций.
*   `numpy` - для математических расчетов.
Также самая первая функция - `pip install xlrd openpyxl`, чтобы можно было читать документы Excel. Нужно просто запустить эту ячейку и подождать пару секунд.

## Как запустить
1. Скачайте архивом репозиторий. Разархивируйте его - важно поместить все файлы в одну папку. Создавать отдельную папку для таблицы `taxes_rus` не надо - она должна быть на одном уровне с `sultanov-project.ipynb`
2. Откройте файл `sultanov-project.ipynb` в Jupyter Notebook.
3. Выполните все ячейки по порядку.

## Основные результаты исследования
*   Выявлено абсолютное доминирование Центрального федерального округа (и особенно Москвы) в структуре налоговых поступлений.
*   Подтверждена сырьевая зависимость экономики России
*   Оценка с учетом инфляции показала, что большинство регионов обеспечили реальный прирост доходов бюджета (более чем в 4,5 раза).
